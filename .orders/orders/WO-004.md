## Intent

Darragh, 2026-10-02: 'We need to loop it better. The black screen sort of kills it.' Measured live (0.5 s samples over a 3-scene turn): the band goes blank for ~1-1.5 s at every scene change and ~2.5 s at session start, while each new helper launches Chromium. Done means the band never blanks once it has shown a picture, and the idle loop has no visible seam.

## Specification

Repo state (main 424e0c5): hooks/terminal/player.ts resets `this.frames = []` when a scene starts (player.ts around line 118), so until the new helper's first frame lands, compose.ts:decodeCells draws its DARK (0x101010) spaces placeholder: the black gap. At session start the restored scene has the same gap. The idle loop replays the last LOOP_SECONDS (2 s) from `count - 2*FPS` (player.ts:frameIndex), and nothing makes its last frame match its first, so the seam can jump. The SVG's `enter: 'fade'` entrance (Director.present adds it on a backdrop change) fades the new scene in from transparent, which renders as black in the helper's frames.

Change (one unit):
1. Hold, then swap. When a new scene starts, keep drawing the previous scene's frames (its loop) and its bubble until the new scene's first frame arrives. Then swap the art and the caption together, so the bubble always matches the picture. Use the dark placeholder only if no picture has been shown since the session started.
2. Session start: until the first frame of the restored scene arrives, draw nothing (pass to the engine), not a dark band.
3. Entrance: on a backdrop change, cross-fade from the previous scene's last frame to the new frames over the entrance (ENTRANCE_SECONDS), blending cells in compose, rather than the SVG fading in from black. Simplest way: the job tells the helper to render the scene without `enter`, and the blend happens in the mod.
4. Seamless loop. Pick the loop start as the frame within the last 4 s whose cells differ least from the final frame (sum of absolute channel differences), so the wrap is the smallest jump available. The loop is at least 1 s long.

Derived requirements: M-01, M-04, M-05, M-06 as before. M-02: desktop untouched. M-03 is unchanged.

## Non-goals

- Caching frames on disk so a new session paints instantly; revisit only if the 1-2 s of nothing at session start bothers Darragh.
- Faster Chromium start (a warm, long-lived browser); the hold-then-swap makes start latency invisible after the first picture.
